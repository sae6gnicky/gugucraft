# ⛏️ 곱셈구구 광산 모험 (Minecraft Multiplication Adventure)

마인크래프트를 좋아하는 어린이들이 **곱셈구구(0×0 ~ 9×9)** 를 재미있게 연습할 수 있는 브라우저 게임입니다.

## 🎮 어떻게 노나요?

1. **index.html 파일을 브라우저로 열면 바로 시작!** (설치 필요 없음)
2. **지도**에서 단계를 고릅니다. 처음엔 **0단**만 열려 있어요.
3. 각 단계에서 **곱셈 문제**가 나오고, 그 단계의 **보스몹**이 함께 등장합니다.
4. 문제를 맞히면:
   - 💰 **코인**을 얻고
   - 들고 있는 **무기로 보스를 공격**해요!
5. 보스를 쓰러뜨리면 **다음 단계가 열립니다.**
6. **0단 → 1단 → ... → 9단 → 랜덤단**(모든 단이 섞여 나옴) 순서로 깨요.

## 🧱 마인크래프트 요소

- **재료 상점**: 모은 코인으로 재료를 사요
  - 나무 · 돌 · 석탄 · 구리 · 철 · 금 · 다이아몬드 · 에메랄드 · 고대 잔해
- **제작대**: 재료를 조합해 **무기**를 만들어요
  - 맨손 → 나무검 → 돌검 → 구리검 → 철검 → 금검 → 다이아몬드검 → **네더라이트검**
  - 특수 조합: 고대 잔해 → 네더라이트 조각 → (조각4 + 금4) → **네더라이트 주괴** → 네더라이트검!
- **보스몹**(단계별, 직접 그린 애니메이션 캐릭터):
  좀비 → 거미 → 스켈레톤 → 크리퍼 → 마녀 → 블레이즈 → 위더 스켈레톤 → 가스트 → 엔더맨 → 위더 → **엔더 드래곤**(최종)

## ✨ 특징

- 📱 PC·태블릿·스마트폰 모두 OK (반응형)
- 🎨 보스몹을 **코드로 직접 그린 벡터 그래픽** — 쿵쿵거리고, 콧김을 뿜고, 날개를 퍼덕이는 애니메이션 (동영상/GIF 파일 없이 선명하게!)
- 🔊 간단한 효과음 (정답/공격/코인/승리)
- 💾 진행 상황 자동 저장 (브라우저에 저장되어 다음에 이어서 플레이)
- 🧒 어린이 친화적인 큰 버튼과 쉬운 안내

## 📂 파일 구성

| 파일 | 설명 |
|------|------|
| `index.html` | 게임 화면 구조 |
| `style.css` | 디자인 + 보스몹 애니메이션 |
| `sprites.js` | 보스/재료/무기 그래픽(SVG) |
| `game.js` | 게임 로직 (문제·전투·상점·제작) |

## 🛠️ 바꾸고 싶다면

- 문제당 코인: `game.js`의 `COIN_PER_CORRECT`
- 단계별 통과 조건: `game.js`의 `STAGES` 안 `need`
- 보스 체력: `game.js`의 `BOSSES` 안 `hp`
- 무기 공격력·레시피: `game.js`의 `WEAPONS`
- 재료 가격: `game.js`의 `MATERIALS`
